# Simple Video Editor

Yeh Android Studio source project hai. App gallery se video select karke 9.9-second ke alag MP4 clips banane ki koshish karta hai.

**Yeh APK file nahi hai.** APK banane ke liye Android SDK/Gradle se build karna aur phone par test karna zaroori hai.

Output: app ke private folder `Android/data/com.example.simplevideoeditor/files/Movies/SimpleVideoEditor` mein.

Note: Copy-based cutting kuch formats/keyframes par exact 9.9 second ya playback compatibility guarantee nahi karta. Project ko test karna zaroori hai.
